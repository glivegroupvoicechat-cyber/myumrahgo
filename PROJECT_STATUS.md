# MyUmrahGo — Project Status

## Current state
The repository is active on `main` and contains the first B2C visual foundation.

## Live code paths
- `/index.html` — B2C landing experience
- `/styles.css` — shared visual foundation
- `/app.js` — initial interactions
- `/pages/package.html` — B2C package detail experience
- `/pages/b2b.html` — B2B partner portal foundation

## Build sequence
1. B2C landing experience — complete foundation
2. B2C package discovery/detail — foundation complete
3. B2C booking/request flow — next
4. Authentication and account area
5. B2B package builder and inventory workflows
6. Admin master panel
7. Database/API/payment integrations
8. QA, security and performance
9. Hostinger deployment + domain + SSL

## Product direction
Premium travel UX, UGC-inspired storytelling, strong curiosity/conversion, mobile-first B2C and operationally efficient B2B.

## Important
Current package prices, inventory, and booking records in the UI are demonstration data only. They must be connected to the real inventory/database before production booking is enabled.
